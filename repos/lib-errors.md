# lib-errors

## Kind
A Spring Boot auto-configuration library (type `lib`) generated by java-skeleton. It carries the
pirca error design: a base exception and `ProblemDetail` answers. It is technical only, with no
business logic.

## Edit
- `src/` (main, test, intTest, archTest): the library code and its tests.
- `README.md`, only when usage, commands or flags change.

## Do not touch
- The Gradle wrapper (`gradlew`, `gradle/wrapper/`).
- The build configuration (`build.gradle`, `gradle/`, `gradle.properties`), unless the card is about
  the build.
- This repository has no `CONTRIBUTING.md` and no `DEVLOG.md`, on purpose: its README and the body of
  each PR cover them. Do not create them.

## Verify
`./gradlew build` in the repository (runs `test`, `intTest` and `archTest`). A criterion that needs
the library published locally is checked through a temporary Maven local, as `qa` does.
